runtime-rocm-2026-11-19.zip: the AMD runtime (paw-vdb3.2): Python 3.12 + the tracker's packages + ffmpeg like the CUDA runtime
(runtime-2026-11-18.txt), with AMD's ROCm-on-Windows PyTorch. The app downloads it as runtime-rocm.zip on a PC with a
discrete AMD card and unpacks it beside the CUDA runtime (paw-vdb3.3, src-tauri/src/portable.rs ZIPS). Git-ignored;
this file is its record. Manifest entry: runtime-rocm in src/features/models/manifest.json.
