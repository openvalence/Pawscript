To make a new one: a python-build-standalone 3.12 folder, python -m pip install the packages above (torch from
https://download.pytorch.org/whl/cu126, the git ones at the pyproject.toml revisions, SAM2_BUILD_CUDA=0), add
pawtrack.pth, the two ffmpeg exes, a new runtime.stamp text, zip as above under a new date; build-nas.ps1 takes the
newest runtime-*.zip.
