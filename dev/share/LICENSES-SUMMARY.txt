PAWSCRIPT: LICENCES IN ONE PAGE
==============================

Pawscript itself is GPL-3.0-or-later (LICENSE, NOTICE). Everything else in this folder keeps its own licence, listed
below. "May it be passed on": yes = permissive, keep the notices (they are in LICENSES\); yes, with notice = the same,
plus the condition named; unclear = no licence file came with it. A summary, not legal advice. Full texts: LICENSES\
(models\ the model licences; THIRD-PARTY-app.md the app's own table). Each Python package's own licence files ship
inside runtime.zip, in python\Lib\site-packages\<package>.dist-info. Where to get the source of the GPL and LGPL parts:
TERMS.txt, section 8.

READ FIRST
----------
GPL      Pawscript (Pawscript.exe, code.zip: trackers\pawtrack): GPL-3.0-or-later, Copyright 2026 AtlanticTM, published
         by OpenValence. Free to share with its source; nobody may make it closed. Source: https://github.com/openvalence/Pawscript
absent   CoTracker3 (Meta, CC BY-NC 4.0: non-commercial only) is not part of this build, and neither is the code that
         would call it: Guide\cotracker.md.
yes, GPL ffmpeg.exe / ffprobe.exe (gyan.dev 8.1.1 "full" build: --enable-gpl --enable-version3, so GPL-3.0) and the
         FFmpeg inside PyAV (runtime.zip: python\...\av.libs: built with libx264 / libx265, so GPL-2.0+): passed on with
         the licence (LICENSES\ffmpeg-LICENSE.txt), the build configuration (LICENSES\ffmpeg-gyan.dev-build-README.txt)
         and the source offer in TERMS.txt.
unclear  Hydra 3.5 tagger (RedRocket): Apache-2.0 according to its model card only; the repository has no licence file.
         It was trained on e621 artwork. LICENSES\models\Hydra-3.5-NOTE.txt.
unclear  NVIDIA CUDA / cuBLAS / cuDNN DLLs inside the PyTorch wheel: NVIDIA's redistribution terms allow shipping them
         with an application (that is how PyTorch ships them), but no NVIDIA licence text came with the wheel.
         LICENSES\NVIDIA-CUDA-NOTE.txt.
