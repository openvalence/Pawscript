6. NOTHING LEAVES YOUR PC
-------------------------
No account, no telemetry, no crash reports, no licence check. The bundled Python is blocked from making any network
connection (trackers\sitecustomize.py); a missing model file is an error, never a download by itself. The app goes
online only when you ask it to:
- Download (the first-start screen, Settings > Models): the runtime and the models you pick, from the Pawscript models
  server (dl.openvalence.org), over HTTPS. Each file is checked against the checksum built into the app before it is kept.
- Check for updates (Help menu, Settings > Updates; at start only if you turn that on, off by default): asks GitHub for
  the newest version; Download and install fetches it, checked against the signing key built into the app.
Nothing is sent but the requests themselves (the server sees your IP address and which file you asked for). The
other connection is to a Valence hub, and only if you set one up and press Connect.

What Pawscript writes, all of it on your own PC:
- Beside your video, continuously while you work: <name>.pawproj (the project), <name>.pawruns (the tracker runs; it
  can reach about 120 MB) and a <name>.pawhistory folder (undo history, checkpoints and commits). The .funscript files
  go beside the video when you Publish; a file Pawscript did not write is kept as a .bak before it is replaced.
- %APPDATA%\app.pawscript.portable: settings, the recent projects list, the window position.
- %LOCALAPPDATA%\app.pawscript.portable: a daily usage log (usage-YYYY-MM-DD.jsonl: the commands and tools you use;
  turn it off with the "Usage log" setting), the fix log (fixes.jsonl: what you corrected of what the app produced,
  same switch), your feedback notes (feedback.jsonl: only what you type into the note field), the part finder's labels,
  small pictures of the frames you labelled and the small model it trains from them (seeder\), project thumbnails,
  autosaves, backups, a media cache (proxies, waveforms, thumbnails; capped, clear it from inside the app) and the
  browser data of the app window (EBWebView\).
- The Pawscript folder itself: the first start unpacks runtime.zip and code.zip into it.
None of it is sent anywhere. To remove it all, delete the Pawscript folder, the two folders above and the files beside
your videos.
