# CoTracker3 (not included)

CoTracker3 is a point tracker by Meta AI. It is not part of Pawscript: its code and its weights are licensed [CC BY-NC 4.0](https://github.com/facebookresearch/co-tracker/blob/main/LICENSE.md), for non-commercial use only, and that license cannot ship inside Pawscript, which is GPL-3.0. This version of Pawscript cannot use it.

Support for CoTracker3 as a separate add-on may come later.

You do not need it: **TAPNext++** is the point tracker, and it did as well or better in our tests.

- A project or setting that used CoTracker3 tracks with TAPNext++ instead (one note says so), or with Optical flow (box) on a PC without an NVIDIA card.
- Runs already tracked with CoTracker3 still load and play.
