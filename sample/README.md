# The Pawscript sample project

A finished example to look around in without bringing a video: Help › Open the sample project (or the button on the empty
Projects page) copies these files to your Videos folder (else Documents), in `Pawscript sample\`, and opens the copy on
the Track tab. The files here are never opened or changed.

| file | what |
|---|---|
| `Pawscript sample.mp4` | 36 s, 1280 x 720, 30 fps, H.264, no audio: an abstract animation, generated |
| `Pawscript sample.pawproj` | the project: three shots, the painted parts (Top hips, Top penis, Bottom hips), shot 1 baked, an anchor, an orgasm modifier with one spurt |
| `Pawscript sample.pawruns` | the tracker run (TAPNext++, a 128-point grid over the whole video, the three parts pinned) |
| `Pawscript sample.pawhistory\` | one commit with a note and the published v1 |
| `Pawscript sample.funscript` | the published v1 |

The clip is generated by `dev/sample/make_sample.py` (deterministic: the same script makes the same frames) and the
project by `dev/sample/build-project.mjs`, through the app's own code and the real tracker. Because the clip is
generated, its true stroke is known (`dev/sample/truth.json`); `test/sample-project.test.mjs` checks the published
script against it.
